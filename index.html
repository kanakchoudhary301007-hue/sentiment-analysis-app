About SentimentAI

A frontend-based sentiment analysis mini project.

Project Overview

SentimentAI analyzes text and classifies its sentiment as Positive, Negative, or Neutral using a rule-based text analysis approach.

Key Features

  • Sentiment classification
  • Confidence, emotion and score display
  • Analysis history saved in LocalStorage
  • Sentiment statistics and chart
  • Dark mode and responsive layout

Technologies Used

HTML, CSS and JavaScript.

Limitations

This project uses rule-based word scoring rather than a trained machine learning model. It may not reliably understand sarcasm or complex context.
